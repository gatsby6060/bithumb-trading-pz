# 빗썸 AI 사용하기

빗썸 AI 를 활용하여 API 문서를 더 빠르고 쉽게 탐색하는 방법을 안내합니다

빗썸 API 문서를 AI와 함께 활용하는 두 가지 방법을 안내합니다.


  
    문서 사이트에서 바로 질문하고 답변을 받습니다.
  

  
    AI 코딩 도구에서 빗썸 API 문서를 참조하며 코드를 작성합니다.
  


## 빗썸 AI로 할 수 있는 것

빗썸 AI는 다음과 같은 질문에 답변하도록 설계되어 있습니다.


  
    원하는 API 문서의 위치를 빠르게 찾을 수 있습니다.

    * "시세 조회 관련 API 어디 있어?"
    * "주문 취소하려면 어떤 엔드포인트를 써야 해?"
  

  
    API 연동 절차와 흐름을 안내받을 수 있습니다.

    * "처음 연동하려면 어떤 순서로 진행해야 해?"
    * "API 키 발급 절차 요약해줘."
  

  
    요청·응답 필드의 의미와 사양을 확인할 수 있습니다.

    * "POST /v2/orders 요청 바디 필드들 설명해줘."
    * "주문하기 요청의 order_type 의미가 뭐야?"
  

  
    에러 코드의 원인과 대응 방법을 확인할 수 있습니다.

    * "403 Forbidden 에러가 나는 이유와 대응 방법 알려줘."
    * "invalid_price_ask 에러 원인이랑 해결 방법 알려줘."
  

  
    다양한 언어의 예제 코드와 샘플 요청을 제공받을 수 있습니다.

    * "BTC-KRW 현재가 조회하는 javascript 예제 보여줘."
    * "WebSocket으로 시세 구독하는 기본 예제 보여줘."
  


> 실제 지원 범위는 사용되는 문서/데이터와 정책에 따라 달라질 수 있습니다.


***

## 사용 방법 및 질문 가이드

### 빗썸 AI 이용 방법

1. API 문서 화면에서 **빗썸 AI**를 엽니다.
2. 동료 개발자에게 묻듯이 **자연어로 질문**을 입력합니다.
   * 예: *"주문 상태 조회하는 API 알려줘."*
3. 답변을 받은 뒤, 같은 대화에서 **추가 질문**으로 내용을 더 구체적으로 물어볼 수 있습니다.
   * 예: *"그럼 잔고 부족일 때 응답 예시도 보여줘."*

### 더 나은 답변을 위한 질문 방법

구체적인 질문일수록 더 정확한 답변을 받을 수 있습니다.


  
    **✅ 좋은 예**

    > "BTC-KRW 현재가를 REST API로 조회하는 방법과 python 예제 알려줘."

    > "GET /v1/orders 호출 시 404 not_found 에러가 나오는데, 가능한 원인과 해결 방법 알려줘."
  

  
    **❌ 덜 좋은 예**

    > "API 좀 알려줘."

    > "에러 나는 이유가 뭘까?"
  


> **질문에 포함하면 좋은 정보**
> 
> * **목적** — 무엇을 하려는지 (예: 현재가 조회, 주문 취소)
> * **API 정보** — 엔드포인트 / HTTP 메서드 (예: `GET /v1/orders`)
> * **문제 상황** — 에러 코드나 에러 메시지 (예: `404 order_not_found`)

## 이용 시 유의사항


> **민감 정보 입력 금지** — 안전한 이용을 위해 다음과 같은 민감한 정보는 입력하지 않도록 유의해 주세요.
> 
> * API Key / Secret Key
> * 인증 토큰
> * 계정 정보(이메일, 비밀번호 등)
> * 기타 개인 정보


### 1. 이용 목적

빗썸 AI는 API 문서 이해를 돕기 위한 보조 도구입니다. 투자 권유, 매매 전략 제안, 자산 운용 자문은 제공하지 않습니다.

### 2. 정확성 및 한계

* 답변은 이해를 돕기 위한 **참고용 안내**입니다.
* 최신 API 사양 및 변경 사항은 반드시 **공식 문서**를 통해 확인해 주세요.
* 제공되는 예제 코드 및 설명은 실제 적용 전에 **충분한 검증**을 거쳐 사용해 주세요.

### 3. 서비스 운영 안내

서비스 품질 개선을 위해 질문 내용 및 처리 관련 정보가 로그로 기록될 수 있습니다. 해당 정보는 **내부 운영 및 품질 개선 목적**으로만 활용됩니다.

### 4. 금지행위 및 책임 제한

사용자는 서비스의 정상적인 운영을 방해하거나 서비스를 오용·악용하는 행위를 하여서는 안 됩니다.

빗썸 AI의 응답은 자동으로 생성되는 안내 정보이며, 빗썸은 해당 응답을 활용하는 과정에서 발생하는 직·간접적인 손실에 대해 책임을 지지 않습니다.

## llms.txt로 AI 코딩하기

이 API 문서 사이트는 **llms.txt** 파일을 제공합니다. llms.txt는 전체 문서의 제목, URL, 본문을 AI가 읽기 쉬운 마크다운 형태로 정리한 파일로, AI 코딩 도구에서 빗썸 API 문서를 참조할 때 사용할 수 있습니다.

👉 **[llms.txt 파일 바로가기](https://apidocs.bithumb.com/llms.txt)**

### 이런 경우에 활용하세요

* **AI 도구에서 활용** — Cursor, Claude Code, ChatGPT 등 AI 도구에 llms.txt URL을 전달하면, 빗썸 API 문서를 기반으로 더 정확한 코드와 답변을 받을 수 있습니다.

### 사용 방법

사용 중인 AI 도구에서 **문서 URL을 등록하거나 대화에 전달**하면 됩니다.

```text
https://apidocs.bithumb.com/llms.txt
```

대부분의 AI 코딩 도구는 외부 문서를 참조하는 기능을 제공합니다. 해당 기능에 위 URL을 입력하세요. LLM과의 대화에서는 URL을 직접 프롬프트에 포함할 수도 있습니다.

### llms.txt에 포함된 정보

| 항목         | 설명                                |
| ---------- | --------------------------------- |
| 페이지 제목과 링크 | 각 문서 페이지의 제목 및 `.md` URL          |
| 본문 내용      | `.md` 링크를 통해 접근 가능한 페이지별 마크다운 텍스트 |
| 문서 유형/구조   | 가이드, API 레퍼런스, 예제 코드, 공지 등 분류 정보  |
