# 가상 자산 투자 이해하기

빗썸 API에서 사용하는 주요 거래, 시세, 입출금 관련 용어를 안내합니다

## 거래 기본 용어

### 거래 대상 페어(Trading Pair)

두 개의 화폐를 조합한 거래 단위입니다. `KRW-BTC`는 원화(KRW)로 비트코인(BTC)을 거래하는 페어를 의미합니다.

* 앞의 화폐: 결제 화폐 (Quote Currency)
* 뒤의 화폐: 거래 대상 화폐 (Base Currency)

API에서는 `market` 파라미터로 사용됩니다.


> [거래 대상 목록 조회](https://apidocs.bithumb.com/docs/거래-대상-목록-조회) API에서 거래 가능한 전체 페어 목록을 확인할 수 있습니다.


### 매수/매도(Bid / Ask)

* **매수(Bid)**: 자산을 사는 행위. API에서 `side: "bid"`로 표현됩니다.
* **매도(Ask)**: 자산을 파는 행위. API에서 `side: "ask"`로 표현됩니다.

### 주문 방식(Order Type)

| 주문 방식  | API 값    | 설명                          |
| ------ | -------- | --------------------------- |
| 지정가    | `limit`  | 사용자가 원하는 가격을 직접 지정하여 주문     |
| 시장가 매수 | `price`  | 현재 시장 가격으로 즉시 매수. 주문 총액을 지정 |
| 시장가 매도 | `market` | 현재 시장 가격으로 즉시 매도. 주문 수량을 지정 |

### 주문 상태(Order State)

| 상태    | API 값    | 설명                             |
| ----- | -------- | ------------------------------ |
| 체결 대기 | `wait`   | 주문이 접수되어 체결을 기다리는 상태           |
| 주문 대기 | `watch`  | 자동주문(예: 예약 주문)이 조건 충족을 기다리는 상태 |
| 체결 완료 | `done`   | 주문 수량이 모두 체결된 상태               |
| 주문 취소 | `cancel` | 사용자 또는 시스템에 의해 주문이 취소된 상태      |

### 체결(Trade Execution)

매수 주문과 매도 주문의 가격이 일치하여 거래가 성사되는 것을 말합니다. 하나의 주문이 여러 건의 체결로 나뉘어 처리될 수 있으며, `trades_count` 필드로 체결 건수를 확인할 수 있습니다.

### 자전거래(Cross Trading)

자신이 등록한 매수 주문과 매도 주문이 서로 체결되는 것을 말합니다. 빗썸 API는 자전거래를 방지하기 위해, 지정가 주문이 본인의 기존 주문과 체결될 가능성이 높은 경우 해당 주문을 자동으로 거부합니다. 이 경우 `cross_trading` 에러가 반환됩니다.

## 시세 정보

### 캔들(Candle)

일정 기간 동안의 가격 변동을 요약한 데이터입니다. 빗썸 API에서는 분(1/3/5/10/15/30/60/240분), 일, 주, 월 단위 캔들을 제공합니다.

각 캔들에는 다음 정보가 포함됩니다:


> [분(Minute) 캔들 조회](https://apidocs.bithumb.com/docs/분minute-캔들-조회), [일(Day) 캔들 조회](https://apidocs.bithumb.com/docs/일day-캔들-조회), [주(Week) 캔들 조회](https://apidocs.bithumb.com/docs/주week-캔들-조회), [월(Month) 캔들 조회](https://apidocs.bithumb.com/docs/월month-캔들-조회)


| 필드              | 설명                    |
| --------------- | --------------------- |
| `opening_price` | 시가 — 해당 기간의 시작 가격     |
| `high_price`    | 고가 — 해당 기간의 최고 가격     |
| `low_price`     | 저가 — 해당 기간의 최저 가격     |
| `trade_price`   | 종가 — 해당 기간의 마지막 거래 가격 |

### 현재가/Ticker

요청 시점의 종목 스냅샷입니다. 시가, 고가, 저가, 종가뿐 아니라 다음 정보도 함께 제공됩니다:

* **전일 종가** (`prev_closing_price`): KST 0시 기준 전일 마지막 거래 가격
* **변화율** (`change_rate`): 전일 종가 대비 가격 변화 비율
* **52주 신고가/신저가**: 최근 52주간의 최고·최저 가격과 달성일
* **누적 거래대금** (`acc_trade_price_24h`): 최근 24시간 동안의 총 거래 금액


> [현재가(Ticker) 조회](https://apidocs.bithumb.com/docs/현재가-조회)


## 호가 정보

### 호가(Orderbook)

현재 시장에 등록되어 있는 매수·매도 주문의 가격과 수량 목록입니다.

* **매도호가** (`ask_price`): 매도 주문이 걸려 있는 가격
* **매수호가** (`bid_price`): 매수 주문이 걸려 있는 가격
* **총 매도 잔량** (`total_ask_size`): 호가에 등록된 전체 매도 수량
* **총 매수 잔량** (`total_bid_size`): 호가에 등록된 전체 매수 수량

단일 거래 대상 페어 조회 시 최대 30호가, 복수 거래 대상 페어 조회 시 15호가까지 제공됩니다.


> [호가(Orderbook) 조회](https://apidocs.bithumb.com/docs/호가-조회)


## 수수료

### 거래 수수료

주문 체결 시 부과되는 수수료입니다. [주문 가능 정보 API](https://apidocs.bithumb.com/docs/주문-가능-정보)에서 마켓별 수수료율을 확인할 수 있습니다.

* `bid_fee` / `ask_fee`: 매수·매도 수수료 비율
* `maker_bid_fee` / `maker_ask_fee`: 메이커 매수·매도 수수료 비율

**Maker와 Taker:**

* **Maker** — 호가에 주문을 등록하여 유동성을 제공하는 주체. 지정가 주문이 즉시 체결되지 않고 호가에 남을 때 Maker가 됩니다.
* **Taker** — 호가에 있는 기존 주문과 즉시 체결되는 주체. 시장가 주문이나 즉시 체결되는 지정가 주문이 Taker에 해당합니다.

일반적으로 Maker 수수료가 Taker 수수료보다 낮습니다.

### 입출금 수수료

가상 자산을 입금하거나 출금할 때 발생하는 수수료입니다. 네트워크별로 수수료가 다를 수 있으며, [입출금 수수료 조회 API](https://apidocs.bithumb.com/docs/입출금-수수료-조회)에서 확인할 수 있습니다.

## 입출금

### 입금 상태

| 구분 | 상태                     | 설명      |
| -- | ---------------------- | ------- |
| 입금 | `DEPOSIT_PROCESSING`   | 입금 대기 중 |
| 입금 | `DEPOSIT_ACCEPTED`     | 입금 완료   |
| 입금 | `DEPOSIT_CANCELLED`    | 입금 취소   |
| 반환 | `REFUNDING_PROCESSING` | 반환 심사 중 |
| 반환 | `REFUNDING_ACCEPTED`   | 반환 완료   |

### 출금 상태

| 상태  | API 값        | 설명           |
| --- | ------------ | ------------ |
| 진행중 | `PROCESSING` | 출금이 처리 중인 상태 |
| 완료  | `DONE`       | 출금이 완료된 상태   |
| 취소됨 | `CANCELED`   | 출금이 취소된 상태   |

### 입출금 현황

각 가상 자산의 입출금 가능 여부와 블록체인 네트워크 상태를 나타냅니다.

| 지갑 상태           | 설명        |
| --------------- | --------- |
| `working`       | 입출금 모두 가능 |
| `withdraw_only` | 출금만 가능    |
| `deposit_only`  | 입금만 가능    |
| `paused`        | 입출금 중단    |

## 경보제

### 유의 종목 / 주의 종목

투자자 보호를 위해 특정 종목에 지정되는 경보 상태입니다.

* **유의 종목** (`market_warning: "CAUTION"`): [거래 대상 목록 조회 API](https://apidocs.bithumb.com/docs/거래-대상-목록-조회)에서 `isDetails=true`로 요청 시 확인 가능
* **주의 종목**: [경보제 API](https://apidocs.bithumb.com/docs/경보제-조회)에서 확인 가능

경보 유형(`warning_type`):

| 유형                                  | 설명         |
| ----------------------------------- | ---------- |
| `PRICE_SUDDEN_FLUCTUATION`          | 가격 급등락     |
| `PRICE_DIFFERENCE_HIGH`             | 글로벌 시세차이   |
| `SPECIFIC_ACCOUNT_HIGH_TRANSACTION` | 소수계정 거래 집중 |
| `TRADING_VOLUME_SUDDEN_FLUCTUATION` | 거래량 급등     |
| `DEPOSIT_AMOUNT_SUDDEN_FLUCTUATION` | 입금량 급등     |

## 고급 주문

### TWAP(Time-Weighted Average Price)

대량 주문을 일정 시간 동안 균등하게 분할하여 체결하는 주문 방식입니다. 시장 충격을 최소화하면서 시간 가중 평균 가격에 가깝게 체결할 수 있습니다.

주요 파라미터:

* `frequency`: 분할 주문 간격 (초)


> [TWAP - 주문 요청](https://apidocs.bithumb.com/docs/twap-주문-요청)


### 다건 주문(Batch Orders)

한 번의 API 요청으로 최대 20건의 주문을 동시에 생성할 수 있는 기능입니다. 다건 주문 취소는 최대 30건까지 가능합니다.


> [다건 주문 요청](https://apidocs.bithumb.com/docs/다건-주문-요청), [다건 주문 취소 접수](https://apidocs.bithumb.com/docs/다건-주문-취소-접수)
