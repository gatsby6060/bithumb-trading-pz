# 빗썸 Developer Docs

빗썸 개발자 문서에서는 시세 조회, 주문, 입출금 등 거래소 기능을 REST API와 WebSocket으로 제공합니다

## 시작하기


  - [빠른 시작 가이드](빠른-시작-가이드): API Key 발급부터 첫 번째 API 호출까지 단계별로 안내합니다.

  - [가상 자산 투자 이해하기](가상-자산-투자-이해하기): 거래 대상 페어, 주문 방식, 캔들 등 API에서 사용하는 주요 개념과 용어를 정리합니다.

  - [빗썸 AI 사용하기](빗썸-ai-assistant-사용하기): AI 어시스턴트와 llms.txt를 활용하여 API 문서를 효율적으로 탐색합니다.


## 개발 가이드


  - [개발 환경 설정하기](개발-환경-설정하기): 언어별 패키지 설치, API 키 관리, 프로젝트 구조를 안내합니다.

  - [인증 토큰 생성하기](인증-토큰-생성하기): JWT 구조, query_hash 생성 규칙, 배열 파라미터 해싱을 설명합니다.

  - [API 호출해 보기](api-호출해-보기): Public API 조회부터 인증이 필요한 Private API 호출까지 실전 시나리오를 다룹니다.


## API 레퍼런스

빗썸 API는 REST API와 WebSocket 두 가지 방식을 제공합니다.


  - [REST API](api-레퍼런스): Public API(시세, 호가, 캔들)와 Private API(계좌, 주문, 입출금)의 전체 엔드포인트를 확인합니다.

  - [WebSocket](기본-정보): 시세, 체결, 호가, 내 주문 등 실시간 데이터를 스트리밍으로 수신합니다.
