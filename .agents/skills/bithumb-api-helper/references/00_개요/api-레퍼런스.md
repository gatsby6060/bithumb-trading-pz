# 개요

빗썸 Open API의 전체 구성과 인증 방식을 안내합니다.

## API 구성

빗썸 API는 **Public API**, **Private API**, **WebSocket** 세 가지로 구분됩니다.

| 구분          | 인증                               | 설명                                            |
| ----------- | -------------------------------- | --------------------------------------------- |
| Public API  | 불필요                              | 시세, 호가, 캔들, 체결 내역 등 시장 데이터를 조회합니다.            |
| Private API | JWT(JSON Web Token) 인증 필요        | 계좌 조회, 주문, 입출금 등 사용자 자산과 관련된 기능을 수행합니다.       |
| WebSocket   | Public: 불필요 / Private: JWT 인증 필요 | 실시간 시세, 호가, 체결, 내 주문, 내 자산 데이터를 스트리밍으로 수신합니다. |

## Base URL

```
REST API:      https://api.bithumb.com
WebSocket:     wss://ws-api.bithumb.com/websocket/v1          (Public)
               wss://ws-api.bithumb.com/websocket/v1/private  (Private)
```

REST API는 버전에 따라 `/v1` 또는 `/v2` 경로를 사용합니다.

## Public API

인증 없이 호출할 수 있는 시장 데이터 조회 API입니다.


  - [거래 대상 목록 조회](거래-대상-목록-조회): 빗썸에서 제공하는 거래 대상 페어(Trading Pairs) 목록을 조회합니다.

  - [캔들 조회](분minute-캔들-조회): 분/일/주/월 단위 캔들 데이터를 조회합니다.

  - [체결(Trade) 내역 조회](체결-내역-조회): 최근 체결된 거래 내역을 조회합니다.

  - [현재가(Ticker) 조회](현재가-조회): 요청 시점의 종목 스냅샷(현재가, 거래량 등)을 조회합니다.

  - [호가(Orderbook) 조회](호가-조회): 지정한 거래 대상 페어의 호가 정보를 조회합니다.

  - [경보제 조회](경보제-조회): 투자 주의가 필요한 거래 대상 페어와 경보 유형 및 단계를 조회합니다.

  - [공지사항 조회](공지사항-조회): 빗썸 공지사항을 조회합니다.

  - [입출금 수수료 조회](입출금-수수료-조회): 빗썸에 상장된 가상자산의 입출금 수수료 정보를 조회합니다.


## Private API

Private API를 호출하려면 JWT 인증이 필요합니다. API KEY와 SECRET KEY로 JWT 토큰을 생성하고, `Authorization` 헤더에 토큰을 포함하여 요청하세요.


> API 레퍼런스의 코드 샘플에서는 편의상 `'발급받은 API KEY'`를 직접 입력하는 형태로 제공됩니다. 실제 프로젝트에서는 `.env` 파일 등을 활용하여 키를 안전하게 관리하세요. 자세한 방법은 [개발 환경 설정하기](https://apidocs.bithumb.com/docs/개발-환경-설정하기)를 참고하세요.

## WebSocket

WebSocket을 사용하면 실시간 데이터를 스트리밍으로 수신할 수 있습니다. REST API는 클라이언트가 반복 요청(폴링)해야 하지만, WebSocket은 한 번 연결하면 서버가 데이터를 지속적으로 푸시합니다. 빈번한 시세 업데이트가 필요한 경우 WebSocket을 사용하세요.

* **접속 제한**: IP당 초당 최대 10회 연결 요청

### Public WebSocket

인증 없이 시장 데이터를 실시간으로 수신합니다.

**엔드포인트**: `wss://ws-api.bithumb.com/websocket/v1`

| 타입                 | 설명                             |
| ------------------ | ------------------------------ |
| **현재가 (Ticker)**   | 종목의 현재가, 변동률, 거래량 등 실시간 시세 스냅샷 |
| **체결 (Trade)**     | 실시간 체결 내역 (체결가, 체결량, 매수/매도 구분) |
| **호가 (Orderbook)** | 실시간 매수/매도 호가 및 잔량              |

### Private WebSocket

JWT 인증을 통해 사용자 개인 데이터를 실시간으로 수신합니다.

**엔드포인트**: `wss://ws-api.bithumb.com/websocket/v1/private`

| 타입                      | 설명                          |
| ----------------------- | --------------------------- |
| **내 주문 및 체결 (MyOrder)** | 내 주문 상태 변경, 체결 내역을 실시간으로 수신 |
| **내 자산 (MyAsset)**      | 보유 자산 잔액 변동을 실시간으로 수신       |
