# 입출금 수수료 조회

빗썸에 상장된 가상자산의 입출금 수수료 정보를 조회합니다.


> #### 안내 사항
> 
> 출금 수수료는 자산별 및 네트워크별 정책에 따라 건당 금액 기준으로 적용되거나, 출금 수량에 비례하는 정률(%) 기준으로 계산될 수 있습니다.
> 
> * 정률(%) 기준 수수료가 적용되는 경우, 실제 출금 수수료는 출금 수량에 `withdraw_rate`를 곱하여 계산합니다.
> * 최소 수수료 또는 최대 수수료가 설정된 경우, 계산된 수수료가 해당 범위를 벗어나면 각각 `withdraw_fee_min` 또는 `withdraw_fee_max`가 적용됩니다.
> * 수수료 금액 관련 값은 모두 해당 출금 자산 단위로 반환됩니다.


  **금액 기준 수수료**

  `withdraw_fee_quantity`만 반환되며, 나머지 필드는 `null`입니다.

  ```json
  {
    "withdraw_fee_quantity": "0.0005",
    "withdraw_rate": null,
    "withdraw_fee_min": null,
    "withdraw_fee_max": null
  }
  ```

  **정률(%) 기준 수수료**

  `withdraw_rate`만 반환되며, 나머지 필드는 `null`입니다.

  ```json
  {
    "withdraw_fee_quantity": null,
    "withdraw_rate": "0.01",
    "withdraw_fee_min": null,
    "withdraw_fee_max": null
  }
  ```

  **정률(%) 기준 수수료(최소/최대 한도 있음)**

  `withdraw_rate`, `withdraw_fee_min`, `withdraw_fee_max`가 함께 반환되며, `withdraw_fee_quantity`는 `null`입니다.

  ```json
  {
    "withdraw_fee_quantity": null,
    "withdraw_rate": "0.01",
    "withdraw_fee_min": "1",
    "withdraw_fee_max": "100"
  }
  ```
