# 공지사항 조회

빗썸 거래소 공지사항을 조회합니다.


> #### 안내사항
> 
> * 현재 API 호출 제한은 IP별 초당 1회로 설정되어 있습니다. 다만, 시스템 상황이나 트래픽에 따라 이 제한은 변경될 수 있습니다.
> * 공지사항 목록은 게시 시각(`published_at`)에 따라 최신 순으로 제공됩니다.


---

## 공지사항 조회

빗썸 거래소 공지사항을 조회합니다.

| 항목 | 내용 |
|------|------|
| **Method** | `GET` |
| **URL** | `https://api.bithumb.com/v1/notices` |
| **인증** | ❌ 인증 불필요 (Public) |
| **Content-Type** | `application/json` |

### 요청 파라미터

#### 쿼리 파라미터

| 파라미터 | 타입 | 필수 | 설명 |
|--------|------|------|------|
| `count` | integer |  | 조회할 공지사항 수(min 1, max 20) |

### 응답

#### `200` ✅ 성공

**응답 예시**

```json
"[\n  {\n    \"categories\": [\n      \"이벤트\",\n      \"안내\"\n    ],\n    \"title\": \"마이쉘(SHELL) 원화 마켓 추가 기념 에어드랍 이벤트\",\n    \"pc_url\": \"https://feed.bithumb.com/notice/1647203\",\n    \"published_at\": \"2025-02-28 15:00:00\",\n    \"modified_at\": \"2025-02-28 14:29:56\"\n  },\n  {\n    \"categories\": [\n      \"마켓추가\"\n    ],\n    \"title\": \"마이쉘(SHELL) 원화 마켓 추가\",\n    \"pc_url\": \"https://feed.bithumb.com/notice/1647199\",\n    \"published_at\": \"2025-02-28 11:12:14\",\n    \"modified_at\": \"2025-02-28 15:10:59\"\n  },\n  {\n    \"categories\": [\n      \"점검\"\n    ],\n    \"title\": \"정부24 점검으로 인한 주민등록증 진위확인 서비스 일시 중단 안내\",\n    \"pc_url\": \"https://feed.bithumb.com/notice/1647039\",\n    \"published_at\": \"2025-02-20 16:00:00\",\n    \"modified_at\": \"2025-02-20 15:06:07\"\n  },\n]"
```

**응답 필드** (배열 항목)

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `categories` | array[string] |  | 공지사항 카테고리 |
| `title` | string |  | 공지사항 제목 |
| `pc_url` | string |  | 공지사항 URL |
| `published_at` | string |  | 공지사항 게시 시각 (형식: yyyy-MM-dd HH:mm:ss) |
| `modified_at` | string |  | 공지사항 수정 시각 (형식: yyyy-MM-dd HH:mm:ss) |

**응답 필드**

### 코드 샘플

#### Javascript

```javascript
const options = {method: 'GET', headers: {accept: 'application/json'}};

fetch('https://api.bithumb.com/v1/notices', options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

#### Python

```python
import requests

url = "https://api.bithumb.com/v1/notices"

headers = {"accept": "application/json"}

response = requests.get(url, headers=headers)

print(response.text)
```

#### Java

```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
  .url("https://api.bithumb.com/v1/notices")
  .get()
  .addHeader("accept", "application/json")
  .build();

Response response = client.newCall(request).execute();
```
