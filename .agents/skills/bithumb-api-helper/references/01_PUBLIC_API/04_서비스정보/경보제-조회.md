## 경보제 조회

투자 주의가 필요한 거래 페어와 경보 유형 및 단계를 조회합니다.

| 항목 | 내용 |
|------|------|
| **Method** | `GET` |
| **URL** | `https://api.bithumb.com/v1/market/virtual_asset_warning` |
| **인증** | ❌ 인증 불필요 (Public) |
| **Content-Type** | `application/json` |

### 요청 파라미터

_요청 파라미터 없음_

### 응답

#### `200` ✅ 성공

**응답 예시**

```json
[
  {
    "market": "KRW-BTC",
    "warning_type": "PRICE_SUDDEN_FLUCTUATION",
    "warning_step": "CAUTION",
    "end_date": "2026-01-15 18:00:00"
  },
  {
    "market": "KRW-ETH",
    "warning_type": "TRADING_VOLUME_SUDDEN_FLUCTUATION",
    "warning_step": "WARNING",
    "end_date": "2026-01-16 12:30:00"
  },
  {
    "market": "BTC-XRP",
    "warning_type": "PRICE_DIFFERENCE_HIGH",
    "warning_step": "DANGER",
    "end_date": "2026-01-17 09:00:00"
  }
]
```

**응답 필드** (배열 항목)

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `market` | string |  | 거래 대상 페어의 고유 심볼 (예시: KRW-BTC) |
| `warning_type` | string |  | 경보 유형 - `PRICE_SUDDEN_FLUCTUATION`: 가격 급등락 - `PRICE_DIFFERENCE_HIGH`: 글로벌 시세 차이 - `SPECIFIC_ACCOUNT_HIGH_TRANSACTION`: 소수계정 거래 집중 - `TRADING_VOLUME_SUDDEN_FLUCTUATION`: 거래량 급등 - `DEPOSIT_AMOUNT_SUDDEN_FLUCTUATION`: 입금량 급등 (enum: `PRICE_SUDDEN_FLUCTUATION`, `PRICE_DIFFERENCE_HIGH`, `SPECIFIC_ACCOUNT_HIGH_TRANSACTION`, `TRADING_VOLUME_SUDDEN_FLUCTUATION`, `DEPOSIT_AMOUNT_SUDDEN_FLUCTUATION`) |
| `warning_step` | string |  | 경보 단계 - `CAUTION`: 주의 - `WARNING`: 경고 - `DANGER`: 위험 (enum: `CAUTION`, `WARNING`, `DANGER`) |
| `end_date` | string |  | 경보 종료 일시(KST) (형식: yyyy-MM-dd HH:mm:ss) |

#### `400` ❌ 오류

**응답 예시**

```json
"{\n    \"error\": {\n        \"name\": 400,\n        \"message\": \"Type mismatch error. Check the parameters type!\"\n    }\n}"
```

**응답 필드**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `error` | object | ✅ |  |

### 코드 샘플

#### Javascript

```javascript
const options = {
  method: 'GET',
  headers: {
    accept: 'application/json',
  },
};

fetch('https://api.bithumb.com/v1/market/virtual_asset_warning', options)
  .then((response) => response.json())
  .then((response) => {
    console.log(response);
  })
  .catch((error) => {
    console.error(error);
  });
```

#### Python

```python
import requests

url = "https://api.bithumb.com/v1/market/virtual_asset_warning"

headers = {
    "accept": "application/json"
}

response = requests.get(url, headers=headers)

print(response.text)
```

#### Java

```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
        .url("https://api.bithumb.com/v1/market/virtual_asset_warning")
        .get()
        .addHeader("accept", "application/json")
        .build();

Response response = client.newCall(request).execute();

System.out.println(response.body().string());
```
