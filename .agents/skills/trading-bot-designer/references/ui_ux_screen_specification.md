# 빗썸 자동매매 시스템 종합 화면설계서 (UI/UX Specification)

본 문서는 피그마(Figma)에 설계된 8개의 메인 화면과 5개의 인터랙티브 모달 상태(State)의 구성 요소, 레이아웃 규격, 사용자 인터랙션 흐름 및 실시간 데이터 매핑 규칙을 명시한 공식 화면설계서입니다.

---

## 1. 글로벌 UI/UX 디자인 시스템 가이드라인

### 1.1 공통 테마 및 색상 규격 (harmonious HSL Dark Theme)
* **Body Background**: HSL(220, 24%, 6%) ➡️ `#0B0F18` (완전한 다크모드 메인 배경)
* **Sub-Panels Background**: HSL(220, 20%, 12%) ➡️ `#121824` (콘텐츠 패널 및 가동 박스)
* **Cards Background**: HSL(220, 16%, 20%) ➡️ `#1E293B` (종목 카드, 인풋 박스, 로그 카드)
* **Primary Text**: HSL(210, 40%, 98%) ➡️ `#F9FAFB` (고대비 메인 가독성 텍스트)
* **Secondary Text**: HSL(215, 16%, 65%) ➡️ `#9CA3AF` (보조 설명, 기본 레이블 텍스트)
* **Accent Colors**:
  * **AI / Success (초록색)**: `#10B981` (AI 오토파일럿 활성화, 매수 뱃지, 실현 이익)
  * **Warning / Pause (황색/오렌지색)**: `#F59E0B` (사용자 규칙 우선 매도 스위치, AI 매도 보조 경고, 손실율)
  * **Error / Panic (적색)**: `#EF4444` (비상 정지, 손절 강행 버튼)
  * **Manual / Info (파란색)**: `#3B82F6` (수동 제어 모드, 매수 수동 전송 버튼)

### 1.2 공통 레이아웃 아키텍처 (Standard 1440x900 Grid)
* **왼쪽 글로벌 네비게이션 메뉴바**:
  * **크기 및 위치**: `x: 0, y: 0, width: 240, height: 900`
  * **구성 요소**: 안티그래비티 봇 서비스 타이틀, 8개 메뉴 탭 리스트(종합 대시보드 ➡️ 종목별 전략 믹서).
* **상단 글로벌 헤더바**:
  * **크기 및 위치**: `x: 240, y: 0, width: 1200, height: 70`
  * **구성 요소**: 현재 화면 타이틀, 시스템 가동 상태 인디케이터(초록색 Ellipse), **비상 정지 (PANIC)** 적색 버튼.
* **메인 콘텐츠 영역 (Main Body)**:
  * **크기 및 위치**: `x: 270, y: 100, width: 1140, height: 780` (오프셋 포함)

## 2. 메인 화면별 레이아웃 및 인터랙션 명세 (Screen 1 ~ 8)

### Screen 1: 종합 관제 대시보드 (x: 0, y: 0)
* **주요 구성 위젯**:
  1. **자산 요약 카드 세트 (x: 270, y: 100, w: 1140, h: 120)**: 총 평가 자산, 가용 원화 잔고, 포트폴리오 리스크 상태(1.85% / 2.0% 한도), 오늘의 실현 손익.
  2. **실시간 틱 캔들 차트 (x: 270, y: 240, w: 560, h: 360)**: 빗썸 웹소켓 API 기반 실시간 BTC/KRW 캔들 드로잉.
  3. **FreqAI 인퍼런스 엔진 현황 (x: 850, y: 240, w: 560, h: 360)**: 현재 예측 시그널(강력 매수 - 신뢰도 84.2%), 에포크 재학습률, 손실율(MSE), MACD/RSI 지표 현황.
  4. **가동 중인 거래 포지션 모니터 (x: 270, y: 620, w: 560, h: 260)**: 보유 종목, 진입가, 현재가, 평가손익(%) 실시간 그리드.
  5. **실시간 가동 로그 요약 (x: 850, y: 620, w: 560, h: 260)**: 틱 수신 속도(1,248 틱/초) 및 백엔드 주요 작동 이벤트 4줄 출력.

### Screen 2: 가동 중인 전략 (x: 1500, y: 0)
* **설명**: 로드된 AI 모델들의 학습 상태와 전략들의 벤치마크 대비 누적 백테스트 수익률 곡선(AI vs Buy & Hold)을 표시 및 감시하는 성능 차트 모니터입니다.

### Screen 3: 상세 거래 내역 (x: 3000, y: 0)
* **핵심 지표 영역 (x: 270, y: 100, w: 1140, h: 120)**: 누적 거래 횟수, 평균 거래 승률(85.2%), Profit Factor(2.42 PF), 최대 낙폭(4.21% MDD) 출력.
* **상세 거래 체결 이력 그리드 (x: 270, y: 240, w: 1140, h: 640)**: 체결 시각, 주문 번호, 총 거래액, 실현 손익(PnL) 테이블. 각 체결 이력을 마우스 클릭 시 **Screen 3-M(체결 영수증)** 모달이 팝업됩니다.

### Screen 4: 시계열 DB 상태 (x: 4500, y: 0)
* **설명**: TimescaleDB의 틱 적재 속도, 디스크 사용량, 구체화 뷰(Continuous Aggregates) 세그먼트 생성 상태를 관제하는 성능 모니터입니다.

### Screen 5: 시스템 로그 콘솔 (x: 6000, y: 0)
* **설명**: 백엔드 터미널 로그 원본 출력을 로그 레벨 필터(ALL, INFO, WARN, ERROR, RISK, API) 버튼 연동을 통해 필터링 검색하는 실시간 디버그 뷰어입니다.

### Screen 6: 수동 및 조건 설정 (x: 9000, y: 0)
* **좌측 패널 (수동 즉시 주문, w: 560, h: 410)**:
  - **거래 대상 종목 선택**: KRW-BTC 등 주문 코인을 바인딩하는 드롭다운 셀렉터.
  - **주문 구분**: 즉시 매수(BUY, 초록) / 즉시 매도(SELL, 적색) 버튼 세트.
  - **주문 입력란**: 주문 가격(KRW) 및 주문 수량(BTC)을 직접 기입. `[빗썸 거래소 주문 즉시 전송]` 클릭 시 **Screen 6-M(주문 확인)** 모달 팝업.
* **좌측 하단 패널 (조건부 규칙 및 우선순위 설정, w: 560, h: 360)**:
  - **우선순위 제어 스위치 (AI vs User)**: 
    - 매수 신호 경합 시: `[AI 판단 우선 (권장)]` (파란색 활성화) / `[사용자 규칙 우선]` (회색 비활성화)
    - 매도 신호 경합 시: `[AI 판단 우선]` (회색 비활성화) / `[사용자 규칙 우선 (보수적 보호)]` (주황색 활성화)
* **우측 패널 (AI 조건 자동 최적화 시스템, w: 550, h: 780)**:
  - 작동 모드(수동 고정 / 수학적 통계 / LLM 종합 추론) 라디오 버튼, 30일 학습 파라미터 산출 결과 및 즉시 적용 버튼.

### Screen 7: 통합 트레이딩 데스크 (x: 10500, y: 0)
* **설명**: 실시간 호가/체결 차트, 수동 주문 데스크, 포지션 요약, 그리고 **제미나이(Gemini) AI의 실시간 투자 의사결정 브리핑 보고서**를 단일 화면에 집중 통합한 프로 트레이더 전용 데스크입니다.
* **인터랙션**: 수동 매도 클릭 시 AI가 1.5초 이내에 시장 상태를 분석(후보고)하여 위험을 알릴 경우 **Screen 7-M(AI 매도 보조 경고)** 모달이 화면 중앙에 팝업됩니다.

### Screen 8: 종목별 전략 믹서 (x: 12000, y: 0)
* **좌측 단 (종목별 운영 현황, w: 280, h: 780)**: 
  - 코인 리스트 카드로, 우측에 `[AI 위임]`(초록) 및 `[수동 제어]`(파란색) 뱃지가 표시되어 현재 권한을 한눈에 식별.
* **중앙 단 (전략 혼합 믹서 패널, w: 540, h: 780)**:
  - **권한 모드 토글**: `수동 조절` / `AI 오토파일럿` 전환 스위치.
  - **전략 비율 도넛 차트**: 믹싱된 전략의 비율(추세추종 50%, 볼린저 30%, AI자체 20%)을 컬러 원형 아크로 표기하며 중앙에 `🎯` 과역 표시.
  - **실시간 가중치 슬라이더**: 
    - 각 슬라이더 라벨 왼쪽에 **삭제 아이콘(`✕`)**이 배치되어 가동 중인 기법도 즉시 제척 가능.
    - 슬라이더 패널 최하단에 **`[+ 새로운 기법 추가 (가용한 50종 라이브러리 연동)]`** 버튼을 배치하여 실시간 종목 운영 중 전략 유연 확장 가능.
  - **AI 추천 배너**: 현재 시장 흐름상 최적 비율 제안 및 `[추천 최적 비율 즉시 적용]` 버튼 연계.
* **우측 단 (시뮬레이션 및 활동 로그, w: 280, h: 780)**:
  - 예상 누적 수익률 백테스트 그래프(Preview Line) 및 AI의 시간별 판단 타임라인 로깅 카드 리스트.

## 3. 인터랙티브 팝업 모달 및 경고창 설계 명세 (Screen 1-M ~ 8-M)

### Screen 1-M: 비상 정지 (PANIC) 최종 승인 모달 (y: 1100 라인)
* **트리거 시점**: 헤더의 `비상 정지 (PANIC)` 버튼 클릭 시.
* **UI 연출**: 본문 전체 60% 블랙 반투명 오버레이 처리. 중앙 모달 박스(440x260, 적색 경고 보더라인 `#EF4444`).
* **텍스트 사양**: `🚨 비상 정지 (PANIC) 최종 승인`, 본문 `이 작업은 즉시 빗썸 거래소의 모든 미체결 주문을 취소하고 현재 보유 중인 모든 가상자산 포지션을 시장가로 전량 매도 청산합니다...`
* **사용자 액션**:
  - `[예, 즉시 전량 매도]` (적색 버튼): 클릭 즉시 백엔드의 비상 정지 루틴(`flatten_positions`)을 호출하고 모든 주문 차단.
  - `[아니오 (취소)]` (회색 버튼): 모달창을 닫고 이전 대시보드로 안전하게 복귀.

### Screen 3-M: 체결 상세 영수증 모달 (y: 1100 라인)
* **트리거 시점**: 과거 거래 내역 리스트의 임의의 거래 행을 클릭했을 때.
* **UI 연출**: 중앙 모달 박스(460x480, 초록색 보더라인 `#10B981`).
* **데이터 바인딩 명세**:
  - 거래 ID, 완료 시각, 거래 유형, 코인 명칭, 체결가, 체결량, 총 대금, 수수료, 실현 손익(+3.12% 초록색 강조).
  - 우측 정렬 레이아웃 적용 (`x: 204, w: 200` 바운더리 준수하여 텍스트 오버플로우 방지).
* **사용자 액션**: `[확인 및 창 닫기]` 버튼 클릭 시 창 닫힘.

### Screen 6-M: 수동 주문 전송 확인창 (y: 1100 라인)
* **트리거 시점**: 수동 주문 데스크의 `빗썸 거래소 주문 즉시 전송` 버튼 클릭 시.
* **UI 연출**: 중앙 모달 박스(440x260, 청색 보더라인 `#3B82F6`).
* **텍스트 사양**: `💰 수동 지정가 매수 주문 전송 확인`, "BTC 0.05개를 91,200,000 KRW에 매수 전송하시겠습니까?" 와 같이 가격/수량 실수 방지용 명세 노출.
* **사용자 액션**: `[예, 주문 즉시 전송]` 클릭 시 빗썸 API로 전송, `[아니오 (주문 취소)]` 클릭 시 주문 취소.

### Screen 7-M: AI 매도 보조 경고 모달 (수동 매도 '후보고' 검증)
* **트리거 시점**: 수동 주문 데스크에서 매도 주문 버튼 클릭 시, 백엔드 검증 모듈이 1.5초 이내에 매도 부적절 판정을 내렸을 때 1회 호출.
* **UI 연출**: 중앙 모달 박스(440x240, 황색 보더라인 `#F59E0B`).
* **텍스트 사양**: `⚠️ AI 매도 보조 경고 (1.5초 실시간 검증)`, "현재 지지선 및 지표 분석 상 즉시 매도할 타이밍이 아닙니다. (AI 예측: 1.2초 내 반등 가능성 82.4% 감지)" 경고 메시지 노출.
* **사용자 액션**: 
  - `[매도 취소 (대기)]` (회색 버튼): 매도 집행을 취소하고 호가창 감시 모드로 복귀.
  - `[매도 강행 (진행)]` (적색 버튼): AI의 조언을 우회하여 빗썸 API로 강제 즉시 매도 주문 전송.

### Screen 8-M: 감시 종목 추가 다이얼로그 (y: 1100 라인)
* **트리거 시점**: 종목별 전략 믹서 좌측 패널 하단의 `[+ 종목 추가]` 버튼 클릭 시.
* **UI 연출**: 중앙 모달 박스(460x440, 초록색 보더라인 `#10B981`).
* **구성 인풋 필드**:
  1. 가상자산 코드 선택 드롭다운 셀렉터 (예: `★ KRW-XRP (리플)`)
  2. FreqAI 자동 매수 임계치 기입 인풋 (예: `75 %`)
  3. 초기 믹싱 전략 가중치 설정: 3개의 분리된 기법 칩 리스트(`✕ RSI 30%`, `✕ 볼린저 40%`, `✕ AI자체 30%`) 및 **`+ 기법 추가 (50종)`** 확장 버튼 연동.
  4. 추가 완료 즉시 자동매매 가동 활성화 토글 스위치 (On 상태).
* **사용자 액션**: `[종목 추가 및 활성화]` 버튼 클릭 시 신규 감시 스레드 가동 및 DB 설정 저장, `[취소 (창 닫기)]` 클릭 시 설정 기각.
